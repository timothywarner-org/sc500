# Lesson 01: Identity Foundations: PIM, RBAC, Custom Roles, and Governance Scope

**Exam SC-500 domain:** Manage identity, access, and governance (20-25%)  
**Study guide sections:** Secure access to resources by using Microsoft Entra ID; Implement governance to enforce security and regulatory compliance

## Learning objectives

- 1.1 Implement and configure Microsoft Entra PIM for Azure resources and Microsoft Entra roles
- 1.2 Manage Azure built-in role assignments at management group, subscription, resource group, and resource scope, and create and manage custom Azure roles
- 1.3 Manage Microsoft Entra directory roles, including creating and managing custom Microsoft Entra roles
- 1.4 Evaluate and remediate overprivileged Azure RBAC assignments using access reviews and PIM, and implement resource locks to protect critical resources

## Hands-on practice

Every demo in this lesson is work you can repeat in your own subscription, mostly in the Azure portal or the Microsoft admin centers. Do each one yourself after you watch it, because clicking through a configuration sticks far better than reading about it.

The scripts and Bicep templates from this lesson's demos are published: [`demos/`](demos/) lists them by stage and links to their folders under `lab/`. Do the [one-time lab setup](../../lab/README.md) first.

## Before you start

- An Azure subscription you control, ideally a dedicated sandbox with a budget alert
- A resource group just for this lesson, so cleanup is a single delete
- Microsoft Entra ID P2 (or Microsoft Entra ID Governance) for Privileged Identity Management and access reviews.
